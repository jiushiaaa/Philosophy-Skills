# 使用合集 / Using the collection

## 中文

1. 用 `npx skills add jiushiaaa/Philosophy-Skills --list` 查看模块。
2. 安装需要的人物；不需要同时安装独立仓库版和合集中的同名模块。
3. 提问时指定思想家、实际问题和证据需求。比较多位人物时，分别列前提、原作依据和不同结论。
4. 自制21个模块默认中性；显式开启人物表达才模拟表达方式。文游只取思想，不接管文风。
5. 上游25个模块的默认规则不同，先查各自SKILL.md与USAGE.md。用于文游时明确要求只分析思想，不模拟人物口吻。
6. 需要确切引语或未覆盖观点时查原典，不把生成文本当成历史发言。

## English

1. List modules with `npx skills add jiushiaaa/Philosophy-Skills --list`.
2. Install the thinkers you need. Avoid installing both the standalone and collection copy of the same skill.
3. Specify the thinker, practical question, and evidence requirements. Compare thinkers through separate premises, sources, and conclusions.
4. Our 21 modules default to neutral analysis. Enable expression simulation explicitly; fiction work uses ideas without taking over the writing voice.
5. The 25 upstream modules may use different defaults. Read their SKILL.md and USAGE.md; explicitly request thought-only analysis for fiction.
6. Verify exact quotations and uncovered claims against primary sources. Generated answers are not historical statements.

README and usage guides are bilingual. Skill bodies and research notes remain in their original languages. / README及使用说明双语，技能正文与研究底稿保留原文。
